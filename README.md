# Air Touch Control System 🖐️🚀

An advanced, real-time spatial computing interface that transforms any standard webcam into an interactive AI trackpad. By leveraging deep learning architectures for high-fidelity hand-gesture recognition and stateful OS automation, this system enables complete touchless execution of desktop controls including precision movement, stateful dragging, rate-based scrolling, and dynamic zooming.

---

## 🛠️ System Architecture & Directory Layout

The project follows a modular, clean Python convention optimized for deployment and version control.

```text
air-touch-control-system/
│
├── dist/                   # Compiled standalone executables (Production builds)
├── venv/                   # Isolated Python Virtual Environment (Git ignored)
├── .gitignore              # Project environment exclusion ruleset
├── main.py                 # Core application script (State Engine & CV Pipeline)
└── README.md               # Complete project documentation and operation manual
```

### File & Directory Descriptions

* **`dist/`**: Contains the finalized, compiled standalone executable (`main.exe`) generated by PyInstaller. This folder represents the production-ready build of the application that can be run without Python installed.
* **`main.py`**: The monolithic application entry point. Houses the OpenCV camera feed capture loop, the MediaPipe Hands semantic framework pipeline, the Exponential Moving Average (EMA) mathematical signal filter, and the state-machine logic executing hardware actions via PyAutoGUI.
* **`.gitignore`**: Explicitly instructs Git to exclude the heavyweight `venv/` binaries, compiled `__pycache__` buffers, and temporary PyInstaller `.spec` metadata sheets from being pushed to the remote repository.
* **`venv/`**: Holds local instances of execution wheels and environmental dependencies, protecting system-level Python installations from conflicts.

## 🔬 Deep Technical Features & Engineering Data

### 1. Spatial Cursor Smoothing (EMA Filter)

Raw camera coordinate streams introduce high-frequency sensor jitter due to lighting fluctuations. To deliver a commercial-grade, fluid cursor glide, this application implements an **Exponential Moving Average (EMA)** linear interpolation filter:

`x_smooth = x_prev + α * (x_target - x_prev)`

* **`smooth_factor` (α = 0.25):** Balances responsiveness and noise suppression. It ensures low latency (< 15ms) while entirely neutralizing hand tremors.

### 2. State-Driven Drag & Drop Engine

Standard gesture clicks suffer from rapid looping (spamming 30 clicks/second). This engine utilizes an explicit state-tracking boolean array (`left_mouse_down = False`).

* **Mechanism:** When proximity metrics cross the pixel threshold, `pyautogui.mouseDown()` latches. It remains bound across coordinate spaces, shifting seamlessly into a hardware drag state until a structural open hand releases the latch via `pyautogui.mouseUp()`.

### 3. Virtual Joystick Rate-Based Engines (Scroll & Zoom)

To solve the **"Air Clutch"** dilemma (where resetting hand positions reverses actions), the application introduces static coordinate anchors.

* **Spatial Anchoring:** The moment an activation gesture triggers, the system samples the current pixel index as a constant structural midpoint anchor (`y_anchor`).
* **Dynamic Delta Scaling:** Movement away from this axis calculates directional rate displacement:

`Scroll Velocity = (y_finger - y_anchor) / 3`

This mathematical abstraction allows hands to remain entirely motionless in physical space while the underlying OS continues scrolling or zooming indefinitely based on vector displacement length.

## 🎛️ Complete Manual of Usage

### 🖥️ Reading the Heads-Up Display (HUD)

The application windows project a real-time, color-coded visual feedback overlay framework so operators understand exactly what action the neural network is executing.

* ⚪ **WHITE (`HOVER / MOVE`)**: Neutral state. Tracking index finger to drive mouse coordinates.
* 🟢 **GREEN (`DRAGGING / LEFT CLICK`)**: Left mouse button is locked down. Active drawing, dragging, or selecting.
* 🔵 **BLUE (`RIGHT CLICK`)**: Context menu instruction dispatched.
* 🟡 **YELLOW (`SCROLLING`)**: Mouse wheels locked into Rate-Based Virtual Joystick.
* 🟣 **PURPLE (`ZOOMING`)**: OS layer injected with a universal scaling factor interface (`Ctrl + Wheel`).

| **Move Cursor**       | Extend Index finger upwards; keep remaining fingers open or relaxed             | `HOVER / MOVE`          | Point 8 (Index Tip) |

### 🕹️ Step-by-Step Operator Instructions

#### 1. Precision Tracking & Clicking

* **Movement:** Elevate your hand into the camera sightline. Keep it **1.5 to 3 feet** away. Guide the mouse using your index tip.
* **Text Selection & Window Dragging:** Hover over the text/window title bar. Pinch **Thumb + Index** tightly. Hold the pinch closed while moving your hand to drag the window or highlight text. Separate your fingers to drop.

#### 2. Using the Scrolling Joystick

* Squeeze your Index and Middle fingers flush together.
* A **Yellow center node** instantly locks in place.
* Pull your hand **downwards below the yellow circle** to glide down long pages smoothly.
* Push your hand **upwards above the circle** to scroll up.
* *The further you pull away from the center node, the faster the page moves.*
* Separate your fingers to release the scroll engine.

#### 3. Using the Zooming Joystick

* Inside a web browser, IDE, or Map application, pinch your **Thumb + Ring finger** together.
* A **Purple center node** locks in place.
* Push your hand **upward** to scale/zoom in seamlessly.
* Pull your hand **downward** to scale/zoom out.
* Separate your fingers to lock onto your chosen zoom tier.

## ⚙️ Dependencies & Installation

### Core Ecosystem

* **Python 3.11**
* **OpenCV (cv2)** – Video stream I/O transformation processing pipeline.
* **MediaPipe (v0.10.14)** – 21-point topological hand structural tracking framework.
* **PyAutoGUI** – Native OS hardware driver abstraction layer.

### System Installation Setup

#### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/air-touch-control-system.git
cd air-touch-control-system
```

#### 2. Build and Initialize a Clean Virtual Environment

```powershell
python -m venv venv
.\venv\Scripts\activate
```

#### 3. Synchronize Package Dependencies

```powershell
pip install opencv-python pyautogui
pip install mediapipe==0.10.14
```

---

### Running the System

```powershell
python main.py
```

*To close out of the system cleanly at any point, focus on the camera frame window and press **`q`** on your keyboard.*

## 📦 Standalone Compilation Build Instructions

To distribute this platform to target computers lacking native Python installations, compile it into an immutable standalone binary using PyInstaller:

### Install PyInstaller

```powershell
pip install pyinstaller
```

### Build Executable

```powershell
pyinstaller --onefile --noconsole --collect-all mediapipe main.py
```

### Build Output

```text
dist/
└── main.exe
```

Upon successful pipeline compilation, extract the finalized executable application (`main.exe`) directly from the newly generated `/dist` directory. You can double-click this file to run the program without requiring Python, a terminal, or an IDE.
